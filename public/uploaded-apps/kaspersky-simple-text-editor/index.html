Kaspersky Simple Text Editor — Welcome Guide

Issue 1 — Your interactive getting-started tour

Contents

    Welcome to Kaspersky Simple Text Editor 🎉

    This is your interactive welcome guide — a fully working document built inside the editor. Every section walks you through a real feature you can start using right now. Edit any part freely, or wipe it and start fresh.

    💡 Tip: The editor auto-saves your work to the browser frequently — after every edit and at regular intervals. Look for the "Autosave active" indicator in the toolbar — you will never lose a draft. If you close and reopen the tab, a prompt will offer to restore your last session.

    Step 1 — Meet the editor

    The application uses a three-panel layout:

    • Editor Panel (left) — toolbar + sidebar with settings and templates
    • Main Canvas (centre) — the editable area you are reading right now
    • Live Preview (right) — real-time email preview with 📱 Mobile / 🖥 Desktop toggle

    At the bottom is the Save & Export Bar — a persistent bar with Save, Load, and all export options always visible.

    Step 2 — Text formatting

    Select any text to see the floating inline toolbar appear above your selection. From there you can:

    • Bold, Italic, Underline, Strikethrough
    • Apply text colour or highlight colour — the colour picker offers an extensive palette, a 12-item recent-colours history, custom hex input, and WCAG contrast checking (AA/AAA compliance)
    • Insert a hyperlink with Ctrl+K
    • Switch between heading levels, bullet or numbered lists, and blockquotes
    • Clear all formatting with one click (Ctrl+Shift+X)

    You can also use the permanent toolbar at the top: Bold Ctrl+B, Italic Ctrl+I, Underline Ctrl+U, Strikethrough Ctrl+Shift+S.

    Step 3 — Headings & Table of Contents

    Headings help both readability and navigation. Every H2 and H3 heading you add is automatically listed in the Table of Contents block at the top. Scroll up to see the Contents block.

    Right-click any paragraph to promote it to H1, H2, or H3 via the context menu. The TOC is highly configurable — use the toolbar controls to change:

    • TOC Style — Numbered, Roman numerals, Letters, Bullets, or None
    • TOC Layout — Default, Kaspersky Digest, Pipe, Dash, Dots leader
    • TOC Alignment — Left or Right
    • TOC Background — any colour via the colour picker
    • TOC Edit — click to rename TOC entries inline without changing the actual headings
    • TOC Reset — regenerate the TOC from current headings (Ctrl+Shift+T)

    Toggle TOC visibility from the sidebar with the Show Contents checkbox.

    Step 4 — Paragraph styling & text presets

    This paragraph has an orange background applied via the ▮ Paragraph background button. Use it for call-out boxes, warnings, or tips.

    This one uses a blue background — great for information panels or featured quotes.

    Click the ⇅ Paragraph spacing button to fine-tune line height (1.0–3.0), margin (top/bottom), and padding for any paragraph.

    The sidebar also provides Text Presets — one-click buttons that apply a complete style in one shot:

    • Body Text — standard paragraph style (14 px, regular)
    • Sub-heading — larger, bolder section sub-titles
    • Article Title — full article heading style
    • Footer Text — smaller, lighter footer content
    • Caption — small italic style for image captions
    • Insert Article Header — inserts a pre-formatted header template

    Step 5 — Lists

    Both bullet and numbered lists are fully supported and render correctly in email clients:

    1. Select text, then click the bullet • or numbered 1. button in the inline toolbar
    2. Press Tab to indent a list item one level deeper
    3. Press Shift+Tab to promote it back up
    4. Toggle list type with Ctrl+Shift+L

    You can switch between list types at any time — the editor preserves your items.

    Step 6 — Tables

    Click the table icon (⊞) in the toolbar to open the Table Creator dialog. It offers a visual 10×10 grid selector plus quick templates:

    Template Description
    Image + Text Left image column + right text column
    Two Columns Two equal-width columns
    Article Block Numbered article with image, title, body
    Data Table 4×3 styled data grid with header row
    Image + Caption Full-width image with caption below

    Once inserted, right-click any cell for the full context menu: insert/delete rows & columns, duplicate row, merge/split cells, Cell Styling (background, text colour, borders, padding, alignment), style entire row or column, and Table Properties. Use Tab/Shift+Tab and arrow keys to navigate between cells.

    Step 7 — Images

    Images can be added in four ways:

    • Click the 🖼️ image button in the toolbar to open a file picker
    • Drag & Drop any image file directly onto the editor
    • Paste from clipboard with Ctrl+V — a modal lets you choose between Embed as Base64 or Insert with URL
    • Drag an image from the Image Library in the sidebar (a reusable collection of saved image URLs)

    Click any image to select it. You will see 8 resize handles — drag a corner (hold Shift for constrained proportions) or side to resize. The Property Panel lets you:

    • Set exact dimensions (width and height in pixels)
    • Choose layout: Inline / Block / Float Left / Float Right
    • Set alignment and add a hyperlink
    • Edit alt text for accessibility

    Right-click for the full Image Context Menu: Replace, Wrap, Align, Add/Remove link, Copy/Paste style, Delete.

    Use the sidebar Image Alt Text Validation to scan all images for missing alt attributes and fix them in bulk.

    Step 8 — Content blocks & drag reorder

    Each heading + its following content forms a content block. Hover over any block to see the drag handle (⠿). You can:

    Action Shortcut
    Move block up / down Alt+↑ / Alt+↓
    Duplicate block Ctrl+D
    Copy / Paste block Ctrl+Shift+C / Ctrl+Shift+V
    Jump to next / prev block Alt+] / Alt+[

    Selected blocks show a teal left-border. Blocks with Outlook-incompatible CSS display a ⚠️ badge — hover to see specific issues. The header and footer are special blocks that always stay at the top and bottom. The Table of Contents updates automatically as you reorder.

    The sidebar provides additional Block Operations: Auto-alternate backgrounds (white ↔ mint), Renumber articles (01, 02, 03…), Apply style to all blocks, Teal sub-headings, and Refresh URLs.

    Step 9 — Starter Kits & Block Templates

    Click the ⚙️ settings icon to open the sidebar. The Starter Kits section scaffolds a complete newsletter in one click:

    • Kaspersky Digest — 4 articles (header + TOC + 4 article blocks + footer)
    • Kaspersky Digest — 8 articles
    • Kaspersky Digest — 12 articles
    • Custom count — enter any number to generate that many article blocks

    Below that is the Block Template Library — drag or click to insert individual templates: Article (white/mint), Two-column (image left/right), Article with arrow link, Hero image, Footer block.

    Step 10 — Tags & categories

    Article blocks can be labelled with tags (category badges like CRM, KORM, Mautic, Mindbox, KL Academy, etc.). Tags appear as coloured pill badges inside each article.

    • Tag Picker — select a predefined tag from the dropdown and click Add
    • One-Click Tags — inline buttons for the most common tags
    • Tag Matrix — a grid view (rows = articles, columns = tags) where you can toggle tags with one click across all articles at once
    • Batch Add / Remove — apply or remove a tag across all article blocks in one go
    • Custom tags — create your own tag labels in the Tag Matrix dialog

    Step 11 — Paste handling

    The editor intelligently handles content pasted from different sources:

    • Word / Google Docs — style-based formatting is converted to semantic tags (<b>, <i>, <a>); all layout rubbish is removed. Only bold, italic, underline, and links survive
    • Plain text (Ctrl+Shift+V) — all HTML is stripped, plain unformatted text is inserted
    • Image from clipboard — a modal appears offering "Embed as Base64" or "Insert with URL"
    • HTML — content is sanitised, preserving only safe tags

    Step 12 — Find & Replace

    Press Ctrl+F or click the 🔍 button to open the Find & Replace dialog. Features include:

    • Navigate through matches with Find Next / Find Previous
    • Case Sensitive toggle for exact matching
    • Regular expression mode for advanced pattern matching
    • Replace single match or Replace All at once
    • Status display shows "Match X of Y" or "Replaced N match(es)"

    Step 13 — Undo / Redo history

    Every change is tracked in a deep history stack. Press Ctrl+Z to undo and Ctrl+Y (or Ctrl+Shift+Z) to redo. Click the 🕐 history button in the toolbar to see a visual timeline of all recorded states — click any entry to jump back to that point. The system captures state after image drag, paste, delete, duplicate, move, and content changes.

    Step 14 — Saving, loading & autosave

    The editor uses its own .mops project format (JSON, v2.1) that preserves everything: content HTML, title, issue, colours, layout dimensions, all image URLs, article overrides, TOC settings, preheader, and dark-mode flag.

    • 💾 Save (Ctrl+S) — download a .mops file
    • 📂 Load — import a .mops or .json project (supports v1.0, v2.0, v2.1 formats)
    • Autosave — automatic saves to localStorage every 2 minutes, 5 seconds after each edit, on tab-hidden, and before page unload. If localStorage is full, falls back to minimal data

    Step 15 — Exporting your document

    The bottom Save & Export Bar provides these options:

    Export What you get Best for
    Download HTML ZIP (HTML + images), Base64 (self-contained), or URL-only Cloud upload, ESP, quick preview
    Download with Background HTML + 1 px background PNG strip Bitrix and similar CMS
    Download for Outlook Inlined CSS, MSO conditionals, table layout Microsoft Outlook rendering
    📋 Copy HTML Outlook-compatible HTML to clipboard Paste directly into email system or CMS

    Step 16 — Page & layout settings

    Right-click in the Live Preview or open the Page Settings panel to configure:

    • Email width — 320–900 px (default 600)
    • Top / Bottom padding — vertical spacing inside the email body
    • Left / Right padding — horizontal margins
    • Page background colour — the outer canvas (visible in desktop clients)
    • Email background colour — the content card background
    • Corner radius — round the email card corners

    Step 17 — Live Preview & inline editing

    The preview panel is not just for viewing — it is a full interactive editing environment:

    • Hover any element to see a teal outline
    • Click to select — an action menu appears with Duplicate, Move, Delete, Convert, Copy/Paste style
    • Double-click to enter inline edit mode — type directly in the preview; changes sync back to the editor
    • Drag blocks to reorder them — a drop indicator shows the landing position; drag to the bottom to delete
    • Right-click to open the preview context menu: change width, padding, colour, corner radius

    When you select an element, the Property Panel appears in the sidebar with context-specific controls: text colour, background, font size/family, line spacing, alignment, and — for images — dimensions, wrap, and alt text. For blocks: background, border, border radius, padding, and quick presets (White / Mint).

    A secondary Figma-style toolbar provides quick Undo/Redo, Insert Image/Table, Page Settings, Clear Highlight, and Find & Replace while in preview editing mode.

    Step 18 — Document operations & comparison

    The sidebar offers powerful document-level operations:

    • New Document — clear everything and start fresh (with confirmation)
    • Import HTML — load an existing HTML file; content is parsed, sanitised, and displayed for editing
    • Preview in Tab — open the final email in a new browser tab exactly as recipients will see it
    • Compare with Reference — a full-screen overlay with three modes:
      • Visual — side-by-side panels with synchronised scrolling
      • HTML Diff — line-by-line code comparison (green = added, red = removed)
      • Structural — block-level comparison showing added, removed, or reordered articles

    Step 19 — Responsive breakpoints, preheader & dark mode

    The sidebar includes advanced email settings:

    • Responsive Breakpoints — configure viewport widths for testing (320, 375, 414 px by default); add custom breakpoints or use quick device presets (iPhone SE, 6–8, Plus, 12–14)
    • Preheader Text — set the hidden preview text that appears in email client inbox previews (not visible in the body)
    • Dark-mode Safe — adds color-scheme meta tags so the exported email renders correctly in dark-mode email clients

    Step 20 — Outlook compatibility & validation

    The editor provides comprehensive Outlook support:

    • Real-time warnings — blocks with unsupported CSS (border-radius on images, background-image on table cells, display:flex, etc.) display a ⚠️ badge; hover for details
    • ✅ Validate Outlook button — runs a full compatibility check and generates a score (0–100) with detailed warnings, errors, and actionable advice
    • Outlook export pipeline — CSS inlining → Outlook-safe conversion (removes transform, animation, flex, grid, filter, box-shadow) → flex-to-table flattening → MSO conditional wrapping

    Additional checks: missing alt text, missing image dimensions, external stylesheets, elements wider than 600 px, missing role="presentation" on layout tables.

    Step 21 — Global image URL management

    The sidebar provides a centralised place to manage all recurring image URLs:

    • Hero Image URL — the header banner image
    • Arrow Image URL — the "read more" arrow used in article links (with alignment control)
    • Contact / Feedback / Footer Banner URLs — footer section images
    • Article Image Pattern — a URL template with {n} placeholder (e.g. https://example.com/digest/25/{n}.png) that auto-fills article images as 01, 02, 03…
    • Per-article overrides — set a custom image URL for individual articles
    • Auto-fill Article Images — apply the pattern to all placeholders at once
    • Bulk Upload — upload multiple images that are assigned to articles in sequence
    • Bulk URL Replace — find-and-replace across all image src attributes
    • Visual Image Grid — a bird's-eye view of all article images with inline editing and replacement

    You are ready! 🚀

    That covers every feature of Kaspersky Simple Text Editor. Now it is your turn — click anywhere above to start editing, replace this guide with your own content, and craft your first professional newsletter.

    Happy writing! — and remember, the live preview on the right always shows exactly what your readers will see. ✨
