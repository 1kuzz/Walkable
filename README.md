# 🌿 Walkable — Маршруты в парках вокруг тебя

> Исследуй, делись и гуляй с умом — платформа для пешеходных маршрутов в городских и загородных парках.

---

## 📌 О проекте

**Walkable** — это веб-приложение, которое помогает пользователям находить, строить и оценивать пешеходные маршруты в парках. Приложение учитывает текущую погоду, показывает доступность троп в реальном времени и позволяет сообществу делиться фотографиями и отзывами.

---

## 🎯 Ключевые возможности

### 🗺️ Интерактивная карта парков
- Карта всех парков в радиусе от пользователя
- Поиск по геолокации или по названию
- Фильтрация по типу парка: городской, лесной, набережная, нацпарк
- Слои карты: маршруты, тропы, точки интереса, фото

### 🚶 Маршруты и тропы
- Популярные маршруты, отсортированные по рейтингу и активности
- Просмотр маршрута на карте с профилем высот
- Отображение длины, сложности, времени прохождения
- Быстрая оценка маршрута под свой уровень подготовки (новичок / средний / опытный)
- Создание собственных маршрутов с расстановкой точек (waypoints)

### 📍 Точки (Waypoints)
- Добавление точек интереса на маршруте: скамейки, смотровые площадки, родники, беседки
- Привязка фото к точке
- Комментарии и оценки точек от сообщества

### 📸 Фото и сообщество
- Загрузка фотографий с прогулок, привязанных к маршруту или точке
- Лента активности: что гуляют другие прямо сейчас
- Профиль пользователя с историей маршрутов и достижениями
- Возможность делиться маршрутом в один клик

### 🌤️ Погода и доступность троп
- Текущая погода в парке (температура, осадки, ветер, видимость)
- Прогноз на 3 дня по каждому парку
- Умная оценка доступности тропы по погоде:
  - ✅ Тропа доступна — сухо, хорошая видимость
  - ⚠️ Возможна грязь — недавний дождь, проверьте покрытие
  - ❌ Тропа закрыта — сильный снег, гололёд, паводок
- Уведомления: «Сегодня отличный день для прогулки в [Парк]!»

## 🖥️ Страницы сайта

### `/` — Главная
- Hero-блок с поиском ближайших парков по геолокации
- Карточки трёх популярных маршрутов рядом
- Погодный виджет
- Призыв присоединиться к сообществу

### `/map` — Карта парков
- Полноэкранная интерактивная карта (Mapbox / Leaflet)
- Боковая панель с фильтрами и списком маршрутов
- Переключение слоёв: спутник / карта / рельеф
- Кластеризация точек при малом масштабе
- Современный дизайн: тёмная/светлая тема, glassmorphism-панели

### `/parks/:id` — Страница парка
- Название, описание, фото обложки
- Карта парка с маршрутами внутри
- Список маршрутов (сортировка: популярные / новые / короткие)
- Текущая погода и прогноз
- Фотолента от посетителей

### `/routes/:id` — Страница маршрута
- Карта маршрута с waypoints
- Профиль высот
- Характеристики: длина, набор высоты, тип покрытия, сложность
- Погодная доступность прямо сейчас
- Отзывы и фото от прошедших маршрут

### `/routes/builder` — Конструктор маршрута
- Рисование маршрута по карте
- Привязка к дорогам/тропам или свободная рисовка
- Добавление waypoints с описанием
- Предпросмотр характеристик маршрута в реальном времени
- Сохранение и публикация

### `/profile` — Профиль пользователя
- Пройденные маршруты и статистика (км, маршрутов, фото)
- Значки и достижения
- Сохранённые маршруты и парки
- История активности

## 🏗️ Технический стек (рекомендуемый)

| Слой | Технология |
|------|------------|
| Фронтенд | Next.js 14+ (App Router), TypeScript |
| Стилизация | Tailwind CSS + shadcn/ui |
| Карты | Mapbox GL JS или MapLibre GL JS |
| Погода | Open-Meteo API (бесплатный) или OpenWeatherMap |
| База данных | PostgreSQL + PostGIS (для геоданных) |
| ORM | Prisma |
| Авторизация | NextAuth.js / Clerk |
| Хранилище фото | Cloudinary или AWS S3 |
| Деплой | Vercel + Railway (БД) |

## 🎨 Дизайн и UX (2025–2026)

- **Карта** — главный элемент интерфейса, занимает максимум пространства
- **Тёмная и светлая темы** с автопереключением по времени суток
- **Glassmorphism + blur** для карточек поверх карты
- **Плавные анимации** при переходах между экранами (Framer Motion)
- **Mobile-first**: полная адаптация под телефон, жесты свайпа
- **Доступность (a11y)**: WCAG 2.2, контраст, aria-метки
- **Нативное ощущение** на мобильном (PWA): добавить на главный экран, работа оффлайн для сохранённых маршрутов

## 🌍 Источники данных

- **Парки и тропы**: OpenStreetMap (Overpass API), данные Министерства природы РФ
- **Погода**: [Open-Meteo](https://open-meteo.com/) — бесплатный, без ключа
- **Геокодирование**: Nominatim (OSM) или Яндекс Геокодер
- **Рельеф**: Mapbox Terrain или OpenTopoData
